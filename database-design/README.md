# Database Design Reference

This is a documentation artifact (DDL schema + a plain-PHP-array reference
copy of the migrations), not the live schema. The actual database that
`laravel-backend` runs against is defined by the Eloquent migrations in
`laravel-backend/database/migrations` — that's what Render actually
executes on deploy. Use this folder to read the full schema at a glance;
change the real one in `laravel-backend/database/migrations`.
